# HESE (Hanyang ERICA Smart Environment)
> **2020 한양대학교 ERICA 메이커톤 참여 프로젝트**  
> **시각장애인을 위한 IoT 스마트홈 제어 애플리케이션**

## 📌 프로젝트 개요
HESE는 시각장애인이 가정 내 IoT 기기를 보다 쉽고 직관적으로 제어할 수 있도록 돕기 위해 개발된 안드로이드 애플리케이션입니다. 2020년 한양대학교 ERICA 메이커톤에서 진행된 프로젝트로, 블루투스 통신을 통해 하드웨어 기기(아두이노 등)를 제어하고 상태를 확인하는 기능을 제공합니다.

## 🛠 주요 기능
- **블루투스 기기 연결**: 주변의 페어링된 블루투스 장치를 검색하고 선택하여 연결할 수 있습니다.
- **실시간 데이터 수신**: IoT 기기로부터 전송되는 상태 데이터를 앱 화면에서 실시간으로 확인할 수 있습니다.
- **기기 제어**: '작동 시작' 및 '작동 중지' 버튼을 통해 연결된 스마트홈 기기를 원격으로 제어합니다.
- **사용자 인터페이스**: 시각장애인을 고려하여 명확한 버튼 구성과 상태 피드백을 제공합니다.

## 🚀 기술 스택
- **Language**: Java
- **Platform**: Android
- **Communication**: Bluetooth API (Classic)
- **IDE**: Android Studio
- **Build Tool**: Gradle

## 💻 실행 방법
1. 안드로이드 기기에서 블루투스를 활성화합니다.
2. 하드웨어 기기(아두이노 블루투스 모듈 등)와 기기를 페어링합니다.
3. 앱을 실행하고 **'연결하기'** 버튼을 눌러 목록에서 해당 기기를 선택합니다.
4. 연결이 완료되면 **'작동시작'** 또는 **'작동중지'** 버튼으로 기기를 제어합니다.
5. 기기로부터 오는 상태 정보는 화면 하단의 **'Receive'** 영역에 표시됩니다.
